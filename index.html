Automatic Link Cleaner

A Discord bot that automatically 'cleans' links. Removes (most) known url tracker parameters, and in some cases provides a better embed via third party links (e.g fixupx, kkinstagram, etc.)

Features


  • Link Cleaning

    Via slash commands, or automatically!


  • Auto Embed Fixing

    For supported platforms!


  • Per-Server Configuration

    Tweak how the bot works!
